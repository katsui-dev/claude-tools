# Phase 2 セットアップ手順（初心者向け）

Phase2で「Googleスプレッドシートに接続する」ための設定手順です。上から順番に進めてください。

## ① テスト用スプレッドシートをGoogle Sheets形式に変換する

Claude Codeがあなたの Googleドライブに、ダミーデータ入りのテスト用ファイル
**`経営ダッシュボードDB_Phase2テスト.xlsx`** をアップロード済みです（本番データではありません）。

このファイルは現在「Excel形式（.xlsx）」のままなので、GASから使えるように
**Googleスプレッドシート形式に変換**する必要があります（1分で終わります）。

1. Googleドライブ（drive.google.com）を開き、`経営ダッシュボードDB_Phase2テスト.xlsx` を探す
2. ファイルをダブルクリックして開く（プレビューが開きます）
3. 上部メニューの **「Google スプレッドシートで開く」** ボタンをクリック
   （またはファイルを開いた状態で「ファイル」→「Google スプレッドシートとして保存」）
4. 新しく開いたスプレッドシートのタブが「本物のGoogleスプレッドシート」です
5. そのスプレッドシートのURLをブラウザのアドレスバーからコピーする
   ```
   https://docs.google.com/spreadsheets/d/【ここがスプレッドシートID】/edit
   ```
   「d/」と「/edit」の間の文字列が **スプレッドシートID** です

## ② GASプロジェクトを作成し、コードを貼り付ける

1. 変換後のスプレッドシートを開いた状態で、メニューの **「拡張機能」→「Apps Script」** をクリック
2. Apps Scriptのエディタが開きます（最初は `Code.gs` という空のファイルがあります）
3. このリポジトリの `gas/` フォルダにある以下の5ファイルの中身を、
   Apps Scriptエディタ側に同じ名前でファイルを作ってコピー＆ペーストしてください
   - `Config.js` → Apps Script側では `Config.gs` として新規作成
   - `Utils.js` → `Utils.gs`
   - `DataAccess.js` → `DataAccess.gs`
   - `Code.js` → 最初からある `Code.gs` の中身を置き換える
   - `appsscript.json` は通常は編集不要（歯車アイコン→「マニフェストファイルを表示」で編集可能）
4. `Config.gs` の1行目付近にある
   ```js
   var SPREADSHEET_ID = '';
   ```
   の `''` の中に、①でコピーしたスプレッドシートIDを貼り付けて保存する
   ```js
   var SPREADSHEET_ID = 'ここに貼り付け';
   ```
5. 上部の保存アイコン（💾）をクリックしてすべて保存する

## ③ GASをWebアプリとして公開（デプロイ）する

1. Apps Scriptエディタ右上の **「デプロイ」→「新しいデプロイ」** をクリック
2. 「種類の選択」（歯車アイコン）で **「ウェブアプリ」** を選ぶ
3. 以下のように設定する
   - 説明：任意（例：Phase2テスト）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（社内利用が前提のため、Phase5で認証を追加する予定です）
4. 「デプロイ」をクリック
5. 初回は権限確認画面が出るので、自分のGoogleアカウントで承認する
   （「このアプリは確認されていません」と出た場合は「詳細」→「（プロジェクト名）に移動」で進めます）
6. デプロイ完了後に表示される **「ウェブアプリのURL」** をコピーする
   ```
   https://script.google.com/macros/s/xxxxxxxxxxxxx/exec
   ```

## ④ フロントエンドにURLを設定する

1. このリポジトリの `frontend/js/config.js` を開く
2. `GAS_WEB_APP_URL: ''` の `''` の中に、③でコピーしたURLを貼り付ける
   ```js
   App.Config = {
     GAS_WEB_APP_URL: 'https://script.google.com/macros/s/xxxxxxxxxxxxx/exec'
   };
   ```
3. 保存する

## ⑤ ブラウザで確認する

1. `frontend/index.html` をブラウザで開く（またはPhase1で使ったURLを再度開く）
2. HOME画面上部に以下のいずれかが表示されます
   - 🟢「実データ表示中」→ 成功。KPIカードの数値がスプレッドシートの`dashboard`シートの値と一致していればOKです
   - 🔴「データ取得に失敗、ダミーデータを表示中」→ 失敗。詳細メッセージを確認してください
     （多くの場合、SPREADSHEET_IDの貼り忘れ、デプロイのアクセス設定、URLのコピーミスが原因です）

うまくいかない場合は、エラーメッセージの内容を教えてください。一緒に確認します。

## 注意事項

- 現在接続されているのは **HOME画面のKPIカード（dashboardシート）のみ** です。
  他の画面（広告販促・集客・タスク等）は引き続きダミーデータのままで、Phase3以降で対応します。
- `経営ダッシュボードDB_Phase2テスト` はテスト用データです。本番のデータが用意できたら、
  同じ列構成の本番用スプレッドシートに差し替え、SPREADSHEET_IDを更新するだけで切り替えられます。
